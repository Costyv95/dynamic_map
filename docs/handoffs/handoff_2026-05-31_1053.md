## Architectural Shift
- **Registry Polymorphism:** Shifted 100% of shortcut rendering from monolithic domain subclasses to dedicated visual micro-primitive rendering functions registered inside a type-agnostic component catalog.
- **Component ID Isolation:** Propagated state overrides to DOM elements via their declarative component IDs rather than hardcoded local class fields, maintaining separation of concerns.
