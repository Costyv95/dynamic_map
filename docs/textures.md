# Object textures — style recipe & generation pipeline

Representational shortcut artwork ("a flamingo lamp should look like a flamingo lamp")
is vector SVG, generated by Claude — either interactively in a Claude Code session or
via `scratch/generate_texture.py`. Every texture follows one **style recipe**, so the
set stays visually consistent no matter when or how a piece was generated.

Only **one artwork per object** is needed: the card derives all state looks
automatically (entity off → dimmed + desaturated, on → full color + light-pool glow
for lights, unavailable → grey + strike). See MapShortcut's one-artwork state styling.

## The style recipe

Every texture MUST follow these rules — they are what makes the set coherent:

1. **Canvas**: `viewBox="0 0 128 128"`, subject centered, ~8px breathing room on all
   sides. Transparent background — no backdrop rectangle.
2. **Form language**: flat illustration built from simple rounded shapes (ellipses,
   rounded rects, smooth paths). No photorealism, no 3D perspective — a straight-on
   or slight three-quarter view.
3. **Color**: 2–4 flat fills per object in saturated but slightly muted mid-tones.
   Shadow tones are the base color mixed toward `#1e293b` (never pure black); highlight
   tones mixed toward white.
4. **Lighting**: single key light from the **top-left**. One subtle linear gradient or
   a lighter overlay shape on upper-left surfaces; darker tone on lower-right.
5. **Outline**: thin `rgba(30, 41, 59, 0.35)` stroke, `stroke-width="2"`,
   `stroke-linejoin="round"` on the main silhouette only (not every inner detail).
6. **Ground shadow**: small ellipse under the object, `fill="rgba(15, 23, 42, 0.18)"`,
   roughly 60% of the object's width.
7. **Technical**: pure vector — no `<text>`, no `<image>`, no external refs, no
   scripts, no CSS classes. Inline attributes only. Keep it under ~4 KB.

## File naming & placement

- `dynamic_map_data/icons/obj_<snake_name>.svg` (e.g. `obj_flamingo_lamp.svg`).
- The editor's icon list picks up everything in `icons/`; set it as the shortcut's
  `image` (or a state's `image`) and the auto-state styling does the rest.

## Generating a new texture

**Interactive (no API key needed):** ask Claude Code —
"generate a texture for a &lt;object&gt; following docs/textures.md" — and it will draw
the SVG directly into `icons/`.

**Scripted (Claude API):**

```bash
python3 scratch/generate_texture.py "flamingo lamp" \
    --detail "a pink flamingo-shaped table lamp, bulb glowing warm inside the body"
```

Auth resolves from `ANTHROPIC_API_KEY` or an `ant auth login` profile. The script
embeds the recipe above, validates the returned SVG parses and honors the technical
rules, and writes it to `--out` (default `./generated_textures/`). Copy/rsync the
result into `dynamic_map_data/icons/` on the HA box.
